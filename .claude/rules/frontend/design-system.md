## Brand Identity

**"Clean, inviting, authentic, and lush"** - digital extension of Brava Island

## Color System (OKLCH)

Two-tier architecture in `apps/web/src/app/globals.css`: Tier 1 defines raw OKLCH values in `:root` / `.dark`; Tier 2 maps them to Tailwind via `@theme inline` (`--color-*` namespace). Read the current values there; don't copy them into components.

**DO**: Use semantic tokens (`bg-surface`, `text-body`, `border-hairline`).
**DON'T**: Use raw OKLCH values, hex colors, or raw Tailwind palette utilities (`bg-red-100`) in components.

## Semantic Tokens (Preferred)

### Backgrounds

| Token | Usage |
|-------|-------|
| `bg-canvas` | Page background |
| `bg-surface` | Cards, sidebars |
| `bg-surface-alt` | Hover states, tertiary backgrounds |

### Text

| Token | Usage |
|-------|-------|
| `text-body` | Main reading text |
| `text-muted` | Secondary text, metadata, captions |
| `text-brand` | Brand-colored text (Ocean Blue) |

### Borders

| Token | Usage |
|-------|-------|
| `border-hairline` | Light dividers |
| `border-edge` | Strong borders |

### Status Colors

`status-error`, `status-success`, `status-warning`, `status-flagged`, `status-info`, each with generated `-surface`, `-surface-hover`, `-ink` and `-edge` variants (e.g. `bg-status-error-surface text-status-error-ink border-status-error-edge`). The variants are generated by `scripts/sync-brand-tokens.mjs` between the `@status-surfaces` markers in `globals.css`; don't hand-edit that block.

## Shape & Elevation

### Border Radius (4 levels)

| Token | Value | Usage |
|-------|-------|-------|
| `rounded-badge` | 8px | Tags, badges, toasts |
| `rounded-button` | 12px | Buttons, inputs, chips |
| `rounded-card` | 12px | Standard cards |
| `rounded-container` | 16px | Featured cards, modals |

### Shadows (5 levels)

| Token | Usage |
|-------|-------|
| `shadow-subtle` | Default cards, inputs |
| `shadow-medium` | Hover states |
| `shadow-elevated` | Dropdowns, popovers |
| `shadow-floating` | Modals, toasts |
| `shadow-lift` | Card hover lift effect |

### Transition Timing

`ease-calm` = `cubic-bezier(0.16, 1, 0.3, 1)` — calm, confident motion.

## Typography

- **Headings**: Fraunces (serif) — variable font with SOFT, WONK axes
- **Body**: Outfit (sans-serif) — geometric, modern

## Utility Classes

| Class | Effect |
|-------|--------|
| `.focus-ring` | Standard focus ring styling |
| `.touch-target` | Minimum 44x44px touch target |
| `.hover-surface` | Subtle hover background |
| `.hover-surface-strong` | Strong hover background |
| `.glass-panel` | Glassmorphism effect |
| `.chrome-bottom-clearance` | Bottom padding that clears the mobile bottom nav |

Conditional classes use `clsx()`; see component-patterns.md.

## Where Components Live

| Path | Contents |
|------|----------|
| `components/ui/` | Reusable, stateless primitives with no app-specific imports (~50 files), e.g. Card, PageHeader, StatusDot, DashedEmptyState, ImageLightbox, FilterChip, toast system |
| `components/catalyst-ui/` | Catalyst UI: 8 files, 9 components (Button, Input, InputGroup, Checkbox, Fieldset, Dialog, Dropdown, Popover, Badge) |
| `components/navigation/` | Site chrome: SiteChrome, Mobile/Tablet/DesktopTopBar, MobileBottomNav, MoreSheet, chrome-parts, and `nav-config.ts` (every destination, defined once) |
| `components/<domain>/` | Domain components that compose primitives with app logic, e.g. `archive-home/`, `place-record/`, `settlements/`, `films/`, `photographs/`, `gallery/`, `content/` |

Check `components/ui/` for an existing primitive before writing a new one. Documentation status (`getTownStatus`, `getEntryStatus`) lives in `lib/status.ts`.

## New Component Checklist

When building new components, ensure:

- [ ] Uses semantic color tokens (not raw OKLCH, hex, or palette utilities)
- [ ] Uses shape tokens (`rounded-card`, etc.)
- [ ] Uses shadow tokens (`shadow-subtle`, etc.)
- [ ] Uses `ease-calm` for transitions
- [ ] Mobile-first responsive
- [ ] Focus states visible (use `.focus-ring`)
- [ ] Touch targets 44x44px minimum (use `.touch-target`)
- [ ] Works in light and dark modes
- [ ] Meets WCAG 2.1 AA contrast

## Key Files

| File | Purpose |
|------|---------|
| `apps/web/src/app/globals.css` | OKLCH variables, `@theme` token mapping, utility classes (Tailwind v4, CSS-first) |
| `apps/web/src/app/layout.tsx` | Font loading (Fraunces, Outfit), theme init |
| `scripts/sync-brand-tokens.mjs` | Generates brand and status token blocks from `brand/assets/palette.json` (`pnpm sync:brand` in apps/web) |

`apps/web/tailwind.config.ts` is not loaded (`globals.css` has no `@config`); don't add tokens there.
